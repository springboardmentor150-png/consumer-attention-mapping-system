# Consumer Attention Mapping System (CAMS)

A production-ready, AI-powered retail analytics platform that analyzes shopper behavior, traffic patterns, dwell times, shelf attention, product engagement, and consumer behavior segments using computer vision, multi-person tracking, head-pose attention estimation, and PostgreSQL.

---

## 🌟 Key Features & Capability Matrix

- 👤 **Shopper Detection & Tracking**: Powered by **YOLOv11** and **ByteTrack** for persistent multi-person tracking across video frames with zero identity persistence or facial recognition.
- 👀 **Head-Pose Attention Estimation**: Uses **MediaPipe FaceMesh** and 3D-to-2D perspective projection (`cv2.solvePnP`) to estimate shopper head orientation (yaw, pitch, roll) and gaze direction toward shelves and products.
- 🗺️ **Multi-Layer Heatmaps**: Generates normalized 2D grid heatmaps for shopper traffic density, shelf attention duration, zone dwell times, and product view intensity.
- 🛍️ **Product Attractiveness Scoring**: Computes weighted attractiveness scores combining attention duration (35%), interaction frequency (25%), pickup rate (20%), conversion rate (15%), and repeat engagement (5%). Displays partial scores when POS purchase data is unintegrated.
- 🧠 **Behavior Segmentation**: Classifies shoppers into transparent behavioral segments (*Explorer*, *Quick Buyer*, *Comparison Shopper*, *Impulse Buyer*, *Brand Loyal Customer*) using rule-based algorithms with human-readable explanations.
- 💡 **Automated Recommendations**: Generates data-driven store optimization suggestions (shelf repositioning, promotional placement, dead zone mitigation).
- 📊 **Automated PDF / Excel / CSV Reports**: Exports complete analytics data with audit metadata and privacy disclaimers.

---

## 🔒 Privacy & Ethical Compliance Standards

> [!IMPORTANT]
> **Zero Facial Recognition**: The system explicitly **does NOT** perform facial recognition, age/gender estimation, or unique identity tracking. All tracking IDs are ephemeral, session-bound integer handles generated by ByteTrack.
>
> **Estimated Attention Disclaimer**: Attention duration and direction are computed via **head-pose orientation estimation** (gaze vector relative to shelf bounding boxes), **NOT true eye-tracking**.
>
> **POS Data Handling**: Purchase conversion rates are disabled when point-of-sale data is unavailable, clearly displaying `"PARTIAL SCORE — Purchase Data Unavailable"` to maintain strict statistical integrity without fabricated metrics.

## ⚡ Quick Start Guide

### 1. Prerequisites

- Python 3.11+
- Node.js 20+ & npm
- PostgreSQL 14+ (or Docker)

### 2. Environment Setup

Copy `.env.example` to `.env` and fill in your PostgreSQL database credentials:

```bash
cp .env.example .env
```

Update your `DATABASE_URL` in `.env`:
```env
DATABASE_URL=postgresql+pg8000://postgres:your_password@localhost:5432/cams_db
SECRET_KEY=your_secure_jwt_secret_key
```

### 3. Backend Setup

```bash
cd backend
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt

# Run Database Migrations
alembic upgrade head

# Start Backend Server
uvicorn app.main:app --reload --port 8000
```

Backend API documentation will be available at:
- **Swagger UI**: `http://localhost:8000/docs`
- **ReDoc**: `http://localhost:8000/redoc`

### 4. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

## 📦 Training Support & Dataset Preparation

The system includes end-to-end dataset conversion and YOLOv11 fine-tuning scripts for 4 major benchmark datasets.

### Dataset Download Links
1. **COCO 2017**: [Kaggle COCO 2017 Dataset](https://www.kaggle.com/datasets/awsaf49/coco-2017-dataset)
2. **Mall Dataset**: [Kaggle Mall Dataset](https://www.kaggle.com/datasets/chaozhuang/mall-dataset)
3. **SKU-110K**: [Kaggle SKU-110K Annotations](https://www.kaggle.com/datasets/ranabanerjee/sku110k-annotations)
4. **RPC (Retail Product Checkout)**: [Kaggle RPC Dataset](https://www.kaggle.com/datasets/diyer22/retail-product-checkout-dataset)

### 1. Convert Datasets to YOLO Format

```bash
# Convert COCO 2017 Person annotations
python scripts/prepare_coco.py --input datasets/coco --output datasets/coco_person

# Convert Mall Dataset annotations
python scripts/prepare_mall.py --input datasets/mall --output datasets/mall_yolo

# Convert SKU-110K dense product annotations
python scripts/prepare_sku110k.py --input datasets/sku110k --output datasets/sku110k_yolo

# Convert RPC 200-category product annotations
python scripts/prepare_rpc.py --input datasets/rpc --output datasets/rpc_yolo
```

### 2. Validate Dataset Integrity

```bash
python scripts/validate_datasets.py
```

### 3. Train YOLOv11 Models

```bash
# Train Person Detector (Overhead Surveillance / Shopper Detection)
python scripts/train_person_detector.py --data datasets/mall_yolo/mall.yaml --epochs 50 --batch 16

# Train Dense Product Detector (SKU-110K)
python scripts/train_product_detector.py --data datasets/sku110k_yolo/sku110k.yaml --epochs 80 --batch 8

# Train Multi-Class Product Recognizer (RPC)
python scripts/train_product_detector.py --data datasets/rpc_yolo/rpc.yaml --epochs 100 --batch 8 --model yolo11s.pt
```
